# Technology logos

Place technology logo images in this folder using these filenames:

- `microsoft-365.svg`
- `azure.svg`
- `fortinet.svg`
- `cisco.svg`
- `vmware.svg`
- `aws.svg`
- `dell.svg`

SVG files work best because they stay sharp at every screen size. PNG and WebP files are also supported if you update the matching filename in `src/App.jsx`.
